## 2. 기획 배경

자취생은 식재료를 소량 구매하기 어렵고, 냉장고 안에 무엇이 남아 있는지 자주 잊는다. 그 결과 소비기한이 지난 재료를 버리거나, 이미 있는 재료를 다시 사게 된다.

FreshKeeper는 **식재료 등록 → 소비기한 확인 → 우선 소비 알림 → 레시피 추천 → 재고 정리**로 이어지는 하나의 행동 흐름을 제공한다. 단순 재고 관리 앱이 아니라, "남은 재료를 먼저 먹게 만드는" 리마인더가 목표다.

### 타깃 사용자

혼자 사는 20~30대 자취생 중, 냉장고 속 재료를 자주 잊고 남기며, 요리는 하고 싶지만 메뉴 결정을 어려워하는 사용자.

## 3. 핵심 기능 3가지

| 기능 | 내용 |
|---|---|
| **간편 식재료 등록** | 식재료명·수량·보관 위치·소비기한을 빠르게 등록하고 카드 형태로 한눈에 확인 |
| **소비기한 우선 알림** | D-3 / D-1 / 당일 단계별 리마인드, 오늘 먼저 먹어야 할 재료를 홈 상단에 노출 |
| **AI 레시피 추천** | 보유 재료 기준으로 레시피 추천, 조리 완료 시 사용한 재료를 재고에서 차감 |

### 디자인 키워드

Clean · Fresh · Friendly · Minimal · Mobile First

## 4. 화면 구성

과제 최소 요구(3개 화면)를 넘어 **총 6개 화면**으로 구성했다.

| 번호 | 화면 | 역할 |
|---|---|---|
| 01 | 홈 | 소비기한 임박 재료, 냉장고 현황, AI 추천 레시피 요약 |
| 02 | 냉장고 | 카테고리 탭 + 2열 식재료 카드로 재고 조회·관리 |
| 03 | 레시피 상세 | 재료 / 가이드 / 팁 탭, 단계별 조리 안내, 저장 |
| 04 | 장보기 | 체크리스트, 빠른 추가, 구매 완료 시 재고 연결 |
| 05 | 리포트 | 주간·월간·연간 절약 수치와 폐기 감소 현황 |
| 06 | 마이페이지 | 프로필, 알림 시점, 식습관 설정 |

하단 내비게이션은 **Home / Refrigerator / Recipe / Shopping / My** 5개로 모든 화면에 공통 적용한다.

### 핵심 사용자 흐름

```text
홈에서 소비기한 임박 재료 확인
  → AI 추천 레시피 카드 선택
  → 레시피 상세에서 재료·조리 가이드 확인
  → 조리 완료 후 사용 재료 차감
  → 냉장고 재고 갱신
```

### 프롬프트 수정 요약

| 단계 | 주요 변경 | 변경 이유 | 결과 |
|---|---|---|---|
| 초안 | 냉장고 관리 앱 기본 키워드만 입력 | 콘셉트를 빠르게 탐색 | 화면 역할·정보 구조가 불명확 |
| 수정 1 | 타깃 · 3개 화면 · 카드 구조 · 하단 내비 명시 | 과제 요구사항과 일관성 확보 | 메인 / 목록 / 상세가 구분됨 |
| 수정 2 | 가로 스와이프 → 세로 스크롤 목록 | 탐색성과 정보 노출 개선 | 추천 레시피를 스크롤로 확인 가능 |
| 수정 3 | 레시피 카드 클릭 + 상세 가이드 추가 | 정적 이미지를 사용자 흐름으로 확장 | 홈 → 레시피 상세 전환 구현 |
| 최종 | 기존 이미지를 유일한 시각 기준으로 지정, 6개 화면 연결 | Figma Make의 임의 재디자인 방지 | 디자인 유지 + 기능 중심 프로토타입 |

### AI 이미지 문제점과 후가공

| 문제 | 수정 방법 |
|---|---|
| 한국어 텍스트 깨짐 | Figma에서 실제 텍스트 레이어로 재입력 |
| 화면별 폰트·간격 편차 | Text Style과 Auto Layout으로 통일 |
| 아이콘 스타일 불일치 | 동일 아이콘 세트로 교체 |
| 하단 내비게이션 차이 | 공통 컴포넌트 1개로 제작해 전 화면 적용 |
| 이미지 잘림 | 390 × 844px 프레임에 맞게 크롭, 기기 목업 제거 |

### 일관성 유지 방법

ChatGPT 이미지 생성에는 고정 시드 입력 기능이 없어, **최종 이미지를 레퍼런스로 반복 사용**하고 동일한 제한 프롬프트(같은 컬러 · 타이포 · 카드 모서리 · 하단 내비, 화면 잘림 금지, 임의 기능 추가 금지)를 모든 단계에 유지했다.

## 7. 회고

**잘된 점**
- 단순 재고 목록이 아니라 알림과 레시피 추천을 하나의 흐름으로 연결
- 최소 3개 화면 요구를 넘어 6개 화면으로 확장
- 추천 레시피를 가로 스와이프 → 세로 스크롤로 개선
- AI 결과를 그대로 쓰지 않고 Figma 후가공 + 프로토타입까지 진행

**한계**
- 생성형 AI만으로는 한국어 텍스트와 픽셀 단위 정렬에 한계
- 실제 소비기한 DB나 식재료 인식 기능은 미구현 (시각적 프로토타입)
- 리포트 절약 금액·통계는 실제 데이터가 아닌 예시 값

**향후 개선**
- 영수증·카메라 촬영을 이용한 식재료 자동 등록
- 조리 완료 후 재고 자동 차감
- 자주 버리는 식재료 분석, 1인분 중심 레시피 추천
